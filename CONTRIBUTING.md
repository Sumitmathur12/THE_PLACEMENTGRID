# Contributing to THE_PLACEMENTGRID

Thank you for your interest in contributing to THE_PLACEMENTGRID! 🚀

THE_PLACEMENTGRID is an open-source placement preparation and career-readiness platform. Contributions from students, developers, educators, and the wider open-source community are welcome.

## How You Can Contribute

You can contribute by:

* Fixing bugs
* Improving documentation
* Adding new features
* Improving UI/UX
* Adding tests
* Improving accessibility
* Improving performance
* Adding placement preparation resources
* Improving AI-assisted features
* Suggesting new ideas
* Reviewing pull requests

## Getting Started

### 1. Fork the Repository

Fork the repository to your own GitHub account.

### 2. Clone Your Fork

```bash
git clone https://github.com/YOUR_USERNAME/THE_PLACEMENTGRID.git
cd THE_PLACEMENTGRID
```

### 3. Create a Branch

Create a separate branch for your work.

```bash
git checkout -b feature/your-feature-name
```

For bug fixes:

```bash
git checkout -b fix/your-fix-name
```

### 4. Install Dependencies

Install the frontend dependencies:

```bash
cd frontend
npm install
```

Install the backend dependencies:

```bash
cd ../backend
npm install
```

### 5. Configure Environment Variables

Create the required `.env` files using the provided environment variable examples.

Never commit API keys, passwords, tokens, or other sensitive information.

### 6. Run the Project

Start the backend and frontend according to the instructions in the main README.

### 7. Make Your Changes

Keep changes focused and avoid unrelated modifications.

### 8. Test Your Changes

Before submitting a pull request:

* Make sure the application builds successfully.
* Test the feature or bug fix locally.
* Make sure existing functionality is not broken.
* Add or update tests when appropriate.

### 9. Commit Your Changes

Use clear commit messages.

Examples:

```text
feat: add company preparation roadmap
fix: resolve authentication issue
docs: improve installation guide
test: add roadmap API tests
refactor: simplify challenge service
```

### 10. Create a Pull Request

Push your branch:

```bash
git push origin feature/your-feature-name
```

Then open a Pull Request against the `main` branch.

## Pull Request Guidelines

Please provide:

* A clear description of the change
* The problem being solved
* Screenshots for UI changes when applicable
* Testing information
* Any relevant issue number

Keep Pull Requests focused and reasonably small when possible.

## Code Style

Please follow the existing project structure and coding conventions.

Avoid unnecessary changes to unrelated files.

## Reporting Bugs

Before creating a bug report, check whether the issue has already been reported.

When reporting a bug, include:

* What happened
* What you expected to happen
* Steps to reproduce
* Browser/device information when relevant
* Screenshots or logs when useful

## Feature Requests

Feature ideas are welcome.

Please explain:

* The problem the feature solves
* Why it would be useful
* How you think it could work

## Security

Do not report security vulnerabilities through public GitHub issues.

Please follow the process described in `SECURITY.md`.

## Community

Please be respectful and constructive when interacting with maintainers and contributors.

The goal of THE_PLACEMENTGRID is to create a useful and welcoming open-source project for students and developers.

Thank you for contributing! ❤️
